# JavaScript Practice Codes

## English

This repository is a personal practice space for learning JavaScript through problem solving.

The purpose of these exercises is not to build production-ready software, but to develop the ability to analyze problems, design algorithms, work with data, recognize limitations, and gradually improve the quality and efficiency of my code.

Some of the solutions in this repository may be simple, inefficient, or intentionally written without advanced techniques. This is part of the learning process. I keep these exercises as a record of how my problem-solving skills develop over time.

### What this repository represents

This repository represents my **learning process**, not the full extent of my programming abilities.

The code here should not be considered representative of the production projects I build or intend to build for real users. In real-world projects, I aim to write cleaner, maintainable, secure, and scalable code, with appropriate attention to performance, architecture, error handling, data volume, and multiple users.

My larger projects and applications are kept separately from this practice repository.

### What I am practicing

Through these exercises, I am gradually working on:

* Problem decomposition
* Algorithmic thinking
* Arrays and objects
* Loops and conditional logic
* Data processing
* Searching and comparison
* Time and space complexity
* Data structures
* Code readability and maintainability
* Improving solutions after understanding the basic approach

The goal is not simply to make a program work, but to understand **why it works, where it becomes inefficient, and how it can be improved.**

### Why keep simple exercises publicly?

I believe that learning is a process, and this repository documents that process.

Rather than presenting only polished final projects, I want this repository to show the progression from basic implementations toward more structured and efficient solutions.

The exercises may therefore vary significantly in quality and complexity as the repository grows.

## فارسی

این مخزن فضای شخصی من برای یادگیری JavaScript از طریق حل مسئله است.

هدف این تمرین‌ها ساخت نرم‌افزارهای آماده برای استفاده‌ی واقعی نیست، بلکه توسعه‌ی توانایی تحلیل مسئله، طراحی الگوریتم، کار با داده‌ها، شناخت محدودیت‌ها و بهبود تدریجی کیفیت و کارایی کد است.

بعضی از راه‌حل‌های این مخزن ممکن است ساده، ناکارآمد یا بدون استفاده از تکنیک‌های پیشرفته باشند. این موضوع بخشی از فرآیند یادگیری است. این تمرین‌ها را نگه می‌دارم تا روند رشد توانایی حل مسئله و برنامه‌نویسی من در طول زمان قابل مشاهده باشد.

### این مخزن چه چیزی را نشان می‌دهد؟

این repository نشان‌دهنده‌ی **فرآیند یادگیری من** است، نه تمام توانایی برنامه‌نویسی من.

کدهای این مخزن نباید به‌عنوان نمونه‌ی کاملی از پروژه‌های واقعی یا production من در نظر گرفته شوند. در پروژه‌هایی که برای کاربران واقعی می‌سازم، هدف من نوشتن کدی تمیز، قابل نگهداری، امن و قابل توسعه است و در آن‌ها موضوعاتی مانند کارایی، معماری، مدیریت خطا، حجم داده و تعداد کاربران را نیز در نظر می‌گیرم.

پروژه‌های بزرگ‌تر و برنامه‌هایی که برای استفاده‌ی واقعی ساخته می‌شوند، جدا از این مخزن نگهداری خواهند شد.

### چه چیزهایی را تمرین می‌کنم؟

در این تمرین‌ها به‌تدریج روی موارد زیر کار می‌کنم:

* تجزیه‌ی مسئله
* تفکر الگوریتمی
* آرایه‌ها و آبجکت‌ها
* حلقه‌ها و منطق شرطی
* پردازش داده
* جست‌وجو و مقایسه
* پیچیدگی زمانی و فضایی
* ساختارهای داده
* خوانایی و نگهداری کد
* بهبود راه‌حل پس از درک روش اولیه

هدف فقط این نیست که یک برنامه کار کند؛ بلکه می‌خواهم بفهمم **چرا کار می‌کند، در چه شرایطی ناکارآمد می‌شود و چگونه می‌توان آن را بهتر کرد.**

### چرا تمرین‌های ساده را عمومی نگه می‌دارم؟

من یادگیری را یک فرآیند می‌دانم و این مخزن بخشی از ثبت همین فرآیند است.

به‌جای اینکه فقط نسخه‌های نهایی و polished کارها را نمایش دهم، می‌خواهم این repository مسیر حرکت از پیاده‌سازی‌های ابتدایی به سمت راه‌حل‌های ساختاریافته‌تر و کارآمدتر را نشان دهد.

بنابراین با رشد این مخزن، طبیعی است که کیفیت و پیچیدگی تمرین‌ها نیز تغییر کند.
